# 📊 Application de Prédiction Client avec Streamlit

Application web interactive pour prédire le comportement des clients à l'aide d'un modèle Random Forest.

## 🚀 Fonctionnalités
- Interface utilisateur simple et intuitive
- Prédiction en temps réel
- Gestion des caractéristiques clients :
  - Âge, solde bancaire, nombre de produits
  - Statut d'activité
  - Sexe et localisation géographique
